## Architecture (target end state)

```
src/
  config.ts                    .env loading + validation + Phase-1 mainnet guard
  types.ts                     PoolSnapshot, Opportunity, AttemptRecord
  logger.ts                    structured JSONL attempt log (logs/attempts.jsonl)
  math/cpmm.ts                 pure constant-product math (x*y=k, fee-aware)
  math/whirlpool.ts            pure sqrtPriceX64 -> price conversion
  detect.ts                    pure opportunity detection over two PoolSnapshots
  datasource/PriceSource.ts    the swappable interface (ADR-0006), push-shaped
  datasource/rateLimiter.ts    token bucket, ceiling below Helius 10 req/s
  datasource/polling.ts        PollingPriceSource: real devnet RPC reads
  datasource/synthetic.ts      SyntheticPriceSource: fixture-driven snapshots
  decode/raydiumCpmm.ts        raw account -> PoolSnapshot (reserves)
  decode/orcaWhirlpool.ts      raw account -> PoolSnapshot (sqrtPrice, liquidity)
  txbuilder/index.ts           ONE atomic tx: buy-cheap leg + sell-expensive leg
  txbuilder/raydiumCpmm.ts     CPMM swap_base_input instruction
  txbuilder/orcaWhirlpool.ts   Whirlpool swap instruction
  executor.ts                  THE single simulate-then-send gate (ADR-0005)
  wallet.ts                    devnet keypair load/generate from KEYPAIR_PATH
  main.ts                      wire together: source -> detect -> build -> execute -> log
tests/
  cpmm.test.ts                 TDD (required by phase doc)
  detect.test.ts               TDD (required by phase doc)
  executor.test.ts             TDD abort-on-failed-simulation (required)
  rateLimiter.test.ts
  config.test.ts               phase guard refuses mainnet in Phase 1
```

Data flow: `PriceSource` pushes timestamped raw-state `PoolSnapshot`s →
`detect.ts` (pure) returns a decision → if profitable, `txbuilder` makes one
atomic tx → `executor` simulates, aborts or sends → every attempt hits
`logger` regardless of outcome. Detection/execution/logging never know which
data source is active (`DATA_SOURCE=polling|synthetic` in .env) — the
synthetic source both enables the "detects a synthetic opportunity" exit
criterion and proves the ADR-0006 swap boundary for real.

Synthetic source note (NEVER_DO compliance): synthetic snapshots are
*inputs* (pool states), clearly labeled `dataSource: "synthetic"` in every
log line. Simulation results are always real RPC output, never fabricated.

## Key numeric decisions (in the plan so they're reviewable)

- CPMM output: `dxFee = dx * (1 - feeBps/10000)`, `out = dxFee * y / (x + dxFee)`.
- Whirlpool price: `(sqrtPriceX64 / 2^64)^2 * 10^(decimalsA - decimalsB)`.
  Phase 1 treats the Whirlpool leg at spot price minus configured
  SLIPPAGE_TOLERANCE_BPS buffer (single-tick-range exact math is a stretch
  task; assumption documented in detect.ts).
- Net profit = sellLegOut − buyLegIn − txFeeLamports(converted) − priority fee;
  profitable only if ≥ MIN_PROFIT_THRESHOLD (config, never weakened).
- Trade size: fixed TRADE_SIZE_USDC from config (optimal-size closed form = stretch).
- All token amounts in bigint base units; no floats in money math.
