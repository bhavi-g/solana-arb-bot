## WHAT I BUILT

- **docs/adr/** — index, template, and ADRs 0001–0006 covering all six
  decisions in phase-1's "ADRs to draft" list, each with explicit
  alternatives and consequences.
- **Config** ([src/config.ts](../../src/config.ts)) — all runtime settings
  from .env; refuses to start if PHASE=1 and cluster/RPC is mainnet
  (NEVER_DO rule enforced as config validation, not a code fork); MAX_RPS
  hard-capped at Helius's 10 req/s; commitment pinned to "processed".
- **Pure math** — constant-product with fee ([src/math/cpmm.ts](../../src/math/cpmm.ts)),
  whirlpool sqrtPriceX64 conversions ([src/math/whirlpool.ts](../../src/math/whirlpool.ts)).
  All bigint; floats only in a logging helper.
- **Detection** ([src/detect.ts](../../src/detect.ts)) — pure function over
  two snapshots, evaluates both directions with executable-amount math,
  subtracts fees, flags only when net profit ≥ threshold. Whirlpool legs
  priced at spot minus the slippage buffer (tick-crossing impact not
  modeled in Phase 1 — documented assumption).
- **Data-source boundary** ([src/datasource/PriceSource.ts](../../src/datasource/PriceSource.ts))
  — push-shaped interface (ADR-0006) with two adapters: polling (one
  batched getMultipleAccounts per cycle through a sliding-window rate
  limiter with 429 backoff) and synthetic (scripted scenario with one
  engineered gap, every snapshot labeled source="synthetic").
- **Decoders** ([src/decode/](../../src/decode/)) — Raydium CPMM
  PoolState/AmmConfig and Orca Whirlpool layouts, offsets verified against
  upstream program source that day; reserves computed as vault balances
  minus accrued protocol/fund/creator fees.
- **Atomic tx builder** ([src/txbuilder/](../../src/txbuilder/)) — both swap
  legs hand-encoded (account order verified against upstream) in ONE
  VersionedTransaction; the sell leg's minimum-out is quoteIn + threshold,
  so profitability is enforced on-chain and unprofitable trades revert.
- **Executor gate** ([src/executor.ts](../../src/executor.ts)) — the only
  module that can send; simulate → abort on error or sub-threshold profit →
  rebuild with CU budget measured from simulation (+15%) → send. Grep
  confirms sendRawTransaction appears nowhere else in src/.
- **Logger** ([src/logger.ts](../../src/logger.ts)) — JSONL line per attempt:
  timestamp, gap, decision, real simulation output, action, reason.
- **Orchestration** ([src/main.ts](../../src/main.ts)) — wiring only.
- **README.md**, **scripts/probe-devnet-pools.ts** (devnet research probe).
